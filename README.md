# 🗑️ Smart Waste Collection System

An intelligent waste collection and monitoring system using web technologies, IoT, and automation.

## 👨‍💻 My Role

Collaborated with a teammate to develop the Web Dashboard Frontend using:
- HTML5
- CSS3
- JavaScript

## 🏗️ Project Structure

```text
Smart-Waste-Collection-System/
├── backend/          # PHP API
├── frontend/         # HTML, CSS, JavaScript
├── Dockerfile.backend
├── Dockerfile.frontend
├── docker-compose.yml
├── nginx.conf
├── .env.example
└── README.md
```

## 🛠️ Technologies

HTML5, CSS3, JavaScript, PHP, MySQL, Docker, Nginx.

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/alaaashraf10/Smart-Waste-Collection-System-.git
cd Smart-Waste-Collection-System-
```

**2. Configure environment variables**

```bash
cp .env.example .env
```

Add your database credentials to `.env`.

**3. Run the project**

```bash
docker compose up -d --build
```

## 🌐 Application URLs

- Frontend: http://localhost:3000/pages/login.html
- Backend: http://localhost:8080
- phpMyAdmin: http://localhost:8081
